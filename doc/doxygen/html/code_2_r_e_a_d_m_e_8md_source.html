15 ## Cluster pre work
16 Because of some wrong default modules and system variables you should run this
17 commands first. If your cluster is set up correctly this may not be necessary
18 . Gnu gcc does not work at the moment due to version 4.8 not supporting
19 c++14 which is required for our project.
20 ```
21 module load cmake
22 module switch intel clang
23 ```

25 ## Automatic Compilation
26 All following steps have to be done in the `code` subfolder.
27 
28 ### Compilation
29 Run `./install.sh` to compile and install the software.
30 There are more options available with the install script,
31 just run `./install.sh --help` to display all available options. For example,
32 if you want to compile in Debug mode use `./install.sh -d`.
33 
34 If you get an Error about "permission denied", type `bash install.sh` or
35 make the script runable with `chmod +x install.sh` and then try again.
36 
37 ### Runnning
38 After running the install script just type `./bin/RealTimefluid` to start the
39 software.
40 Do not run it out of the `bin` folder direct because of resources dependencies.
41 
42 ## Manual Compilation
43 All following steps also have to be done in the `code` subfolder.
44 
45 ### Compilation
46 This show how to compile with cmake.
47 ```
48 mkdir build
49 cmake .. -DCMAKE_BUILD_TYPE=Release
50 make
51 make install
52 cd ../

56 # Additional information
57 
58 The software loads all images and strings out of the `res/` folder. This
59 folder contains a file called `index.properties`. All displayed texts and
60 images are referenced or stored directly here. For future changes this makes it
61  a lot easier to correct spelling mistakes or even translate the
62  software to a different language.
