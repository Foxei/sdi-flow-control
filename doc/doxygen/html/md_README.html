Installation

System prerequisites:

Requiered:

  • CMake 2.7
  • Make (Or equivalent make tool)
  • C++ Compiler (clang 3.5+ with omp, gnu 5.2+)
  • Qt 5.0+
  • OMP
  • Boost

Optional:

  • Doxygen

Cluster pre work

Because of some wrong default modules and system variables you should run this commands first. If your cluster is set up correctly this may not be necessary . Gnu gcc does not work at the moment due to version 4.8 not supporting c++14 which is required for our project.

1 module load cmake
2 module switch intel clang

Automatic Compilation

All following steps have to be done in the code subfolder.

Compilation

Run ./install.sh to compile and install the software. There are more options available with the install script, just run ./install.sh --help to display all available options. For example, if you want to compile in Debug mode use ./install.sh -d.

If you get an Error about "permission denied", type bash install.sh or make the script runable with chmod +x install.sh and then try again.

Runnning

After running the install script just type ./bin/RealTimefluid to start the software. Do not run it out of the bin folder direct because of resources dependencies.

Manual Compilation

All following steps also have to be done in the code subfolder.

Compilation

This show how to compile with cmake.

1 mkdir build
2 cmake .. -DCMAKE_BUILD_TYPE=Release
3 make
4 make install
5 cd ../
6 ./bin/RealtimeFluid

Additional information

The software loads all images and strings out of the res/ folder. This folder contains a file called index.properties. All displayed texts and images are referenced or stored directly here. For future changes this makes it a lot easier to correct spelling mistakes or even translate the software to a different language.
